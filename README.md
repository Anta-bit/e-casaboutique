# Casa Boutique - E-Commerce Platform

Platform e-commerce moderne et complète pour la vente en ligne de produits.

> [!TIP]
> **Nouveau sur le projet ?** Consultez notre [Guide d'Installation et de Démarrage pour Débutants (GUIDE_INSTALLATION_DEBUTANT.md)](./GUIDE_INSTALLATION_DEBUTANT.md) pour apprendre à lancer l'application étape par étape, depuis l'installation de Node.js jusqu'à React.


## 🚀 Fonctionnalités

### Client
- ✅ Page d'accueil moderne (design type Jumia)
- ✅ Catalogue de produits dynamique
- ✅ Gestion du panier
- ✅ Paiement en ligne (PayTech, Wave, Orange Money)
- ✅ Gestion du compte client
- ✅ Suivi des commandes
- ✅ Système vocale multilingue

### Admin
- ✅ Gestion des produits
- ✅ Gestion des catégories
- ✅ Gestion des commandes
- ✅ Gestion des clients
- ✅ Gestion des fournisseurs
- ✅ Gestion des paiements
- ✅ Statistiques de vente

## 🛠️ Technologies

- **Frontend**: React JS, Tailwind CSS/Bootstrap
- **Backend**: Node.js, Express
- **Base de données**: MySQL
- **APIs**: PayTech, Wave, Orange Money
- **Authentification**: JWT
- **Voice**: Web Speech API

## 📁 Structure du projet

```
casaboutique/
├── frontend/          # Application React
├── backend/           # API Express
├── database/          # Schéma MySQL
└── docs/             # Documentation
```

## 📝 Installation

### Frontend
```bash
cd frontend
npm install
npm start
```

### Backend
```bash
cd backend
npm install
npm start
```

### Base de données
```bash
mysql -u root -p < database/schema.sql
```
